# MoonPay reference material

The desktop layout is adapted from the published iPhone screenshots for MoonPay
2.0.54, particularly the flat Total value header, Buy/Deposit pills, Assets/Wallets
tabs, dark holdings list, and purple primary actions.

- Official app listing and app icon: https://apps.apple.com/us/app/id1635031432
- Screenshot/icon metadata: https://itunes.apple.com/lookup?id=1635031432&country=us
- Official website: https://www.moonpay.com/
- Official wordmark: https://www.moonpay.com/logos/moonpay-dark.svg

The icon is MoonPay's App Store artwork, saved locally for offline use. The
application is a local visual demo, not an official MoonPay client. No MoonPay
credentials, payment connection, or genuine wallet integration is provided.

The legacy folder, browser profile, and localStorage key remain in place solely
to preserve the existing local balances, transactions, and USB registration.
